# 天気に応じた服装提案アプリ

現在地または都市名から天気を取得し、気温・湿度・風速・天気（雨/雪/晴れ）をまとめて判断して服装を提案するWebアプリです。  
「何を着ればいいか」を迷わないように、基本アイテムに加えて雨対策や体感面の注意もあわせて表示します。

## 主な機能

- **現在地の天気取得**（Geolocation API）
- **都市名検索**（日本語/英語どちらでも検索可能）
  - 例：`東京` / `Tokyo` / `杉並区` / `川崎市` / `埼玉県`
- **服装提案**
  - 気温（7段階）をベースに、湿度・風速・天気で調整
  - **基本アイテム / アウター / 履物 / 小物**のカテゴリで表示
- **時間帯別（朝/昼/夜）のアドバイス**
  - 予報（3時間ごと）から近い時間帯の情報を使って表示
- **降水確率の表示**
  - 現在に近い予報から降水確率を取り、雨対策の判断材料にしています
- **エラーハンドリング**
  - 位置情報が使えない場合の案内（HTTPS・権限拒否など）を表示

## 技術スタック

- Next.js（App Router）
- React / TypeScript
- Chakra UI
- OpenWeatherMap API（現在天気 + 予報）
- Geolocation API
